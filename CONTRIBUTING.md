# Contributing to Kizu

Thank you for your interest in Kizu.

Kizu is currently maintained solely by the author, so pull request and issue
creation is restricted to maintainers on GitHub (`Collaborators only`). Once
Kizu enters the 1.0 maintenance phase and adoption grows, we will reconsider
this policy.

## Feedback, bug reports, and ideas

[GitHub Discussions](https://github.com/kizu-lang/kizu/discussions) is open to
everyone for questions, bug reports, feedback, and design ideas. The author
reviews posts there and decides what to address directly.
